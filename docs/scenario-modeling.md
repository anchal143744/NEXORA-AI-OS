# Scenario Modeling

Version: 0.30.0

Scenario Modeling enables what-if analysis, base/best/worst cases, stress testing and strategic impact review.

## Capabilities

- Scenario models with base case, assumptions and variables.
- Scenario results with KPI impacts, financial impact, risk impact and recommended actions.
- Scenario studio and what-if API surfaces.
- Integration with forecasts, strategic plans and AI Strategy Copilot.
