
# Renewal Intelligence

Renewal intelligence turns upcoming contract renewal windows into an operational system. It combines renewal schedules, forecasts, risk bands, playbooks and owner assignment.

## Capabilities

- Renewal schedules with notice dates, owner assignment, amount and probability.
- Renewal forecasts with expected amount, forecast period, assumptions, drivers and recommendations.
- Renewal dashboard metrics for open renewals, forecast count and high-risk renewal forecasts.
- Event publication for created schedules and forecasts.

## API Surface

- /v1/renewals/dashboard
- /v1/renewals/schedules
- /v1/renewals/forecasts
