# Data Warehouse

Version: 0.31.0

The Data Warehouse layer provides analytics warehouses, domain data marts, warehouse jobs and data pipeline operations.

## Capabilities

- Warehouse registry with engine, schema, refresh cadence and governance metadata.
- Data mart architecture for finance, CRM, product, operations and executive domains.
- Warehouse job tracking with status, duration, rows processed and metrics.
- Data warehouse explorer APIs.

## API Groups

- /v1/data-warehouse
- /v1/data-marts
- /v1/data-pipelines

## Database Models

- DataWarehouse
- DataMart
- WarehouseJob
- DataPipeline
