# ModelOps

Version: 0.32.0

ModelOps manages AI model versions, deployments, environments, rollout health and approval workflows.

## Capabilities

- AI model registry and model version lifecycle.
- Deployment tracking by environment, health status and traffic percentage.
- Risk-tiered model approval workflows.
- Release, rollback and retirement metadata.

## API Groups

- /v1/model-registry
- /v1/modelops
- /v1/model-performance

## Database Models

- AIModel
- AIModelVersion
- AIModelDeployment
- ModelApprovalWorkflow
- ModelPerformanceMetric
