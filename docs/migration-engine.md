# Migration Engine

Phase 20 adds external migration adapter foundations.

## Supported Adapters

- Salesforce
- HubSpot
- Zoho
- Monday
- Notion

## Capabilities

- Migration connections.
- Field mappings.
- Migration runs.
- Adapter metadata and default maps.
- Execution report with normalized preview and failure counts.

## API Group

- `/v1/migrations`

## Models

- `MigrationConnection`
- `MigrationRun`
- `MigrationMapping`
