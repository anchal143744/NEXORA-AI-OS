# Executive Analytics

Version: 0.31.0

Executive Analytics combines data marts, semantic metrics, KPIs and dashboards into a governed business intelligence layer.

## Capabilities

- Executive dashboards with widgets, filters, layout and audience metadata.
- KPI Studio for KPI creation, KPI result generation and scorecards.
- Cross-module reporting across CRM, finance, HR, product, workflow and service data marts.
- Enterprise Dashboard Builder frontend foundation.

## API Groups

- /v1/executive-dashboards
- /v1/kpis
- /v1/data-marts

## Database Models

- ExecutiveDashboard
- KPI
- KPIResult
- DataMart
