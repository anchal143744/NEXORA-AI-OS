# Ecosystem Marketplace

Phase 38 adds the external app directory, partner marketplace and integration catalog.

## Capabilities

- Partner listings with certification levels, countries, industries and support links.
- Marketplace applications with pricing model, rating, permissions and screenshots.
- External integrations with provider, category, auth type, configuration schema and health status.
- Ecosystem events for partner and integration activity tracking.

## API Groups

- /v1/integrations
- /v1/partner-marketplace
- /v1/ecosystem
