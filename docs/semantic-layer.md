# Semantic Layer

Version: 0.31.0

The BI Semantic Layer creates certified business definitions for metrics, dimensions and KPI calculations.

## Capabilities

- Semantic metrics with formula, aggregation, unit, filters and certification status.
- Semantic dimensions with source field, hierarchy and values preview.
- Certified metrics for cross-module reporting and executive dashboards.
- KPI definitions connected to semantic metrics.

## API Groups

- /v1/semantic-layer
- /v1/kpis

## Database Models

- SemanticMetric
- SemanticDimension
- KPI
- KPIResult
