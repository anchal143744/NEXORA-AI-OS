# Workflow Builder Model

Workflow components:
- trigger
- condition
- action
- delay
- approval
- loop
- branch
- ai_decision
- webhook
- integration
- notification

Triggers include business events, manual trigger, API trigger and webhook trigger. Conditions support deterministic operators plus ai_condition. Actions cover tasks, projects, notifications, email, CRM records, finance records, AI analysis, webhooks, reports, employee assignment and follow-up scheduling.
