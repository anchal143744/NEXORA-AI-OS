# Platform Governance

Phase 37 turns NEXORA into a governed platform economy layer.

## Capabilities

- Platform Governance Center for contracts, API products, billing and usage.
- Governance policies with enforcement modes and approval workflows.
- Rate-limit policies, quotas and partner access controls.
- Tenant and workspace isolation through request context.
- Domain events for contract, product, plan, subscription, usage, billing, quota, policy, rate-limit and partner-access activity.

## Frontend

- API Marketplace Dashboard.
- API Governance Center.
- Usage Analytics Workspace.
- Billing Management Dashboard.
- Partner Access Manager.
