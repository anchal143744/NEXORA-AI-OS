# API Monetization

Phase 37 creates API products, monetization plans, subscriptions, metered usage, quotas and rate-limit policies.

## Capabilities

- API marketplace product registry.
- Pricing plan metadata with monthly, request-based and overage pricing.
- API subscriptions bound to products, plans and governed API keys.
- Metered usage records for billing, analytics and quota enforcement.
- Product, plan, subscription and partner access dashboards.

## API Groups

- /v1/api-products
- /v1/api-monetization
- /v1/api-usage
- /v1/api-keys
