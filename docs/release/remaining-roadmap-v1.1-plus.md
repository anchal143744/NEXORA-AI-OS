# Remaining Roadmap v1.1+

Version 1.1+ should focus on release-gate closure and measured hardening, not broad feature expansion.

## Priority 1

- Live full user journey E2E: signup, login, verification, organization creation, workspace creation, team invitation and workspace access.
- Dependency advisory remediation.
- Lighthouse and automated accessibility testing.
- Staging deployment with managed PostgreSQL, Redis, S3-compatible storage and OTLP collector.

## Priority 2

- Load testing for API, queues, realtime and dashboard rendering.
- More integration tests for tenant isolation, RBAC and workflow execution.
- AI Copilot action dispatch validation for audited mutating commands.

## Priority 3

- Expanded screenshots, demo video and public release notes.
- Enterprise onboarding playbook and support runbook.
