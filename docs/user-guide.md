# User Guide

## First User Journey

1. Open /welcome.
2. Select signup.
3. Create an account with name, company, email and password.
4. The backend is designed to create a tenant, organization, business and first workspace for the first account.
5. Complete onboarding.
6. Use business discovery to choose industry, size, goals and operating profile.
7. Generate the workspace blueprint.
8. Open the command center and workspace launcher.
9. Navigate to CRM, People, Finance, Analytics and AI Agents.

## Core Workspaces

- CRM: revenue overview, leads, pipeline, activity and AI Sales Copilot surfaces.
- People: employee directory, attendance, leave, hiring, performance, learning and workforce analytics surfaces.
- Finance: revenue, billing, invoices, payments, budgets, cash flow and finance analytics surfaces.
- Analytics: executive intelligence, KPI management, BI dashboards, reports and strategic insights surfaces.
- AI Agents: agent builder, templates, deployments, monitoring, automations and ROI surfaces.

## Known User-Facing Gaps

- Email verification UI is not yet complete.
- Team invitations require a backend /v1/invites implementation.
- Some AI commands currently return intelligence responses rather than executing live platform actions.
- Live workflows require configured API, database, Redis and email settings.
