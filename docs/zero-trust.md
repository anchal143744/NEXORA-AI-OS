# Zero Trust

Phase 33 adds a zero trust access layer for adaptive policy enforcement and access verification.

## Capabilities

- Risk-aware policy registry.
- Access verification records with decision, trust level and context.
- Support for allow, step-up and deny decisions.
- Policy-level monitoring for active controls and denied access.

## Security Controls

Zero trust records are tenant scoped, workspace scoped, auditable and connected to the security command center through realtime domain events.
