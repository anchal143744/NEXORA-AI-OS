# Enterprise Admin Operations

Phase 19 introduces a tenant-aware enterprise operations layer for global administration.

## Admin Center

- Organization management views.
- Workspace management views.
- User administration views.
- Subscription monitoring.
- AI usage monitoring.
- Admin operation tracking.

## Security Operations

- Tenant suspension.
- Tenant restoration.
- Emergency control activation and deactivation.
- Global permission review.
- Incident creation, listing and resolution.

## API Groups

- `/v1/admin-center`
- `/v1/security-operations`

## Data Models

- `AdminOperation`
- `TenantSuspension`
- `EmergencyControl`
- `AdminIncident`
- `AiUsageSnapshot`
