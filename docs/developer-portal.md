# Developer Portal

Phase 38 adds the developer portal foundation for external API and app ecosystems.

## Capabilities

- Developer accounts with verification and billing profile metadata.
- Developer applications with scopes, redirect URIs, webhook URLs and approvals.
- API documentation hub with OpenAPI-ready specs, examples and publication controls.
- SDK Distribution Center with language packages, release notes, checksums and downloads.

## API Groups

- /v1/developer-portal
- /v1/api-docs
- /v1/sdk
