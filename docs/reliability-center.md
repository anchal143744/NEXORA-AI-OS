# Reliability Center

Phase 34 adds the reliability command plane for NEXORA AI.

## Capabilities

- Reliability Command Center for service health, incidents, uptime, scaling and global operations.
- Reliability intelligence that combines SLO breaches, recovery queues, region health and capacity forecasts.
- Tenant and workspace scoped service health, uptime and score records.

## API Groups

- `/v1/reliability`
- `/v1/uptime`
- `/v1/health`

## Data Boundaries

All reliability records carry tenant scope, optional workspace scope, timestamps, soft deletes and operational indexes.
