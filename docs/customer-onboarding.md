# Customer Onboarding

Phase 20 adds enterprise customer onboarding infrastructure.

## Capabilities

- Business onboarding wizard.
- Industry selection.
- Module, workflow and AI agent recommendations.
- Workspace blueprint generation through the adaptive workspace engine.
- AI onboarding assistant using the existing AI provider abstraction.
- Onboarding steps and recommendation records.

## API Group

- `/v1/customer-onboarding`

## Models

- `OnboardingProfile`
- `OnboardingStep`
- `OnboardingRecommendation`
