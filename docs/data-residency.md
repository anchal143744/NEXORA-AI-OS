# Data Residency

Phase 36 adds the enterprise data residency command plane for NEXORA AI.

## Capabilities

- Data Residency Center for regions, policies, assignments and storage locations.
- Regional data governance by country, jurisdiction and data class.
- Residency assignment tracking for business records, customers, AI memory and regulated data.
- Tenant and workspace scoped residency records with timestamps, soft deletes and indexes.

## API Groups

- `/v1/data-residency`
- `/v1/data-regions`
