# Agent Orchestration

NEXORA AI includes a foundation agent runtime with CRM, Sales, Finance, HR, Operations, Analytics, Customer Success and Executive agents.

Agents can:
- Read workspace context.
- Read events.
- Read workflow state.
- Generate recommendations.
- Trigger downstream work through queues and events.
- Generate reports, create tasks and create alerts through runtime capabilities.

Agent execution is queued through agent-execution and follow-up analysis is queued through agent-analysis.
