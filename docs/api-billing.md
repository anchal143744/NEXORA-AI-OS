# API Billing

Phase 37 adds the API Billing Engine for platform monetization.

## Capabilities

- Billing records by subscription and plan.
- Billing periods, usage units, subtotal, tax amount and total amount.
- Status tracking for open, paid and internal billing records.
- API usage records connected to subscriptions and products.
- Billing dashboards for partner and internal API consumption.

## Database

- ApiBilling
- ApiUsageRecord
- ApiPlan
- ApiSubscription
- ApiQuota
