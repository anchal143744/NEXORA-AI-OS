# Integration Engine

The integration engine manages connector registration, tenant connections, encrypted credentials and connector runtime execution. Supported connectors include Google, Microsoft, Slack, Discord, HubSpot, Salesforce, Stripe, Razorpay, Shopify, WooCommerce, Notion, GitHub, GitLab, OpenAI, Anthropic, Twilio and WhatsApp Business.

Connections are tenant scoped, auditable and event driven.
