# Context Engine

The Context Engine assembles the operational picture needed by automation, executive intelligence and AI execution.

## Context Sources

`ContextEngineService` collects:

- Business context.
- Workspace context.
- Revenue context.
- KPI context.
- Department context.
- User context.
- Workflow context.
- Agent context.
- Business memory.

## Persistence

Every assembled context is written to `business_contexts` with:

- `tenantId`
- `workspaceId`
- `businessId`
- `contextType`
- JSON payload
- timestamps and soft delete support

This makes AI and workflow decisions auditable and reproducible.

## API Surface

- `GET /v1/knowledge-graph/business-context`

## Design Rules

- Context assembly is tenant-aware.
- Workspace scope comes from either request query or active request context.
- The service reads existing operational tables rather than duplicating module logic.
- Context snapshots are generated by the graph service when a graph representation is requested.
