# FinOps

Phase 35 adds the enterprise FinOps command plane for NEXORA AI.

## Capabilities

- FinOps Command Center for cost, usage, budgets, optimization and savings.
- Department cost allocation through cost centers and resource allocation records.
- Cost governance through policies, budget tracking and cost alerts.
- Tenant and workspace scoped FinOps records with timestamps, soft deletes and indexes.

## API Groups

- `/v1/finops`
- `/v1/budgets`
- `/v1/efficiency`
