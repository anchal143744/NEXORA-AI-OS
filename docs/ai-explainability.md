# AI Explainability

Version: 0.32.0

The AI Explainability layer captures rationale, factors, counterfactuals and confidence for AI model outputs and decisions.

## Capabilities

- Explainability records linked to models, versions and decisions.
- Factor extraction for explainable outcomes.
- Counterfactual storage for decision review.
- Explainability records connected to auditability and compliance workflows.

## API Groups

- /v1/ai-explainability
- /v1/ai-audit
- /v1/ai-compliance

## Database Models

- AIExplainabilityRecord
- AIDecision
- AIAuditLog
- AIComplianceRecord
